# اوج فیتنس — نسخه نمایشی

وب‌سایت چندصفحه‌ای فارسی با HTML، CSS و JavaScript خالص؛ قابل انتشار روی GitHub Pages.

## اجرا
فایل `index.html` را باز کنید یا کل پوشه را روی GitHub Pages منتشر کنید.

## صفحات
خانه، کلاس‌ها، مربیان، عضویت، برنامه هفتگی، مسیرهای پیشرفت، مجله، تماس و 404.

## امکانات
- فیلتر کلاس‌ها و برنامه هفتگی
- سوییچ قیمت ماهانه/سالانه
- محاسبه‌گر BMI با توضیح محدودیت آن
- فرم نمایشی رزرو جلسه آزمایشی
- طراحی واکنش‌گرا و منوی موبایل

## نکات دمو
نام برند، اطلاعات تماس، قیمت‌ها، کلاس‌ها و تصاویر نمونه هستند. فرم‌ها به سرور متصل نیستند. BMI ابزار تشخیصی پزشکی نیست. تصاویر از Unsplash بارگذاری می‌شوند و برای نمایش تصاویر به اینترنت نیاز است.
